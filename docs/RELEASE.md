# 0.22.0 源码发布候选

本候选保留应用源码、依赖锁文件、确定性测试、空白导入模板、构建与维护入口。真实模式保持空白。历史开发档案、原始交付包、重复研究草稿和个人运行产物未纳入。

与本地开发版本的发布调整：

- 移除按个人需求预置的侧栏分组、显示名和观察标签。
- 工作区身份改为新克隆本地生成；公开配置只提供不含身份的模板。
- 增加源码边界检查、Git 忽略规则、跨环境操作说明和 CI 配置。
- 计划回归测试使用重新分配的测试产品身份；业务计算与公开来源解析规则保持原有实现。
- 重新整理研究模块来源清单，只列本包内文件完整性，不携带原始来件的指纹。

本文件不声称 GitHub Actions 已经运行、不声称其他机器可直接运行本机二进制，也不声称策略或预测已证明盈利。

当前发布范围为应用源码，安装包另行准备。项目尚未设置开源许可证。
