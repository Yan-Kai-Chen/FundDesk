# 架构与数据口径

`src/frontend` 负责交互和展示；`src/backend/app/domain` 使用 Decimal 计算金融金额；`services` 负责业务编排；`providers` 适配公开行情和合成数据；`persistence` 保存事件与版本化文档。`src/desktop` 使用 Swift / AppKit / WKWebView 承载本地界面，PyInstaller 打包后端。

后端只监听回环地址。前端通过本机会话和 CSRF 校验访问 API。此架构面向个人电脑，未设计为可直接暴露到互联网的多用户服务。

真实与演示数据使用不同数据库。正式净值、第三方估算、本地参考估算、用户人工记录分别标识。估算可以用于已注明口径的界面重估，不改写正式金融事实。申请、确认、退款和到账分开登记，系统推算结果保留推算来源与可校正性。

底仓和 T 仓是经济分仓。T 卖出先消耗 T 仓，不足时补扣底仓成本；实际渠道批次费用按 FIFO 规则计算。卖出价差参考、实现损益和累计收益变化分开，不能重复计入收益。

计划规则只提供参考与表单预填，不自动提交交易。研究模块、净值预测和前向成绩单分别保存；历史重建、冻结预测和首次正式结果不可混作已验证的实盘表现。
